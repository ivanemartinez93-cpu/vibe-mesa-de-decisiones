# Registro de construcción y pruebas

Fuente: trabajo realizado con Codex el 12/11/2026 para Introducción al Vibe Coding. Los textos de abajo son resúmenes de instrucciones y decisiones, no transcripciones literales de todos los prompts.

1. Necesidad: una herramienta útil para organizar alternativas y contexto de decisiones mientras trabajamos en proyectos. Alcance inicial: fichas locales en HTML, CSS y JavaScript sin conexión automática a IA.
2. Construcción: se prepararon el alcance y el contexto; se crearon por separado estructura, estilos y lógica. El historial del repositorio registra los pasos de publicación de esos archivos.
3. Prueba: el navegador rechazó el formulario sin tema; una ficha sintética se guardó, sobrevivió a la recarga y mostró confirmación al copiar contexto. Se consultó el registro de errores de consola y no mostró errores en esa sesión.
4. Refinamiento: se detectó que no había forma de retirar una ficha. Se añadió el botón Eliminar con confirmación. Se observó el botón, pero la eliminación no se ha probado aún.
5. Despliegue: GitHub Pages mostró el sitio público y se comprobó crear y recuperar una ficha sintética al recargar. La comprobación no equivale a una prueba de usuario independiente ni a garantía de fiabilidad.

Límites: no se ha integrado con el flujo n8n ni con conversaciones. El almacenamiento se circunscribe al navegador y origen del sitio; se debe exportar para respaldo. No incluir información sensible. La captura de la preentrega técnica es visual y el código debe verificarse en los archivos fuente, ya que el PDF presenta cortes de líneas.
